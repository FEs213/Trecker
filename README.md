# Trecker
Мобильное приложение для учёта личных расходов: траты по категориям, поездки и командировки, импорт из CSV. Оформлено в тёмной теме Red Velvet по макетам Aurora OS UI Kit.

### Поддерживаемые платформы
- Android (эмулятор, настоящее устройство)
- Web (Chrome, для быстрой проверки интерфейса)

### Функционал
- Обзор расходов за месяц: кольцевая диаграмма по категориям с процентами, столбики по последним шести месяцам, переключение месяцев.
- Список расходов с поиском по получателю и комментарию, группировка по месяцам.
- Фильтры расходов: категории, период дат, сумма больше или меньше порога, способ оплаты, командировка. Все условия применяются вместе.
- Добавление расхода: сумма (с копейками), категория, дата, получатель, комментарий, способ оплаты.
- Проверка формы перед сохранением.
- Детали расхода: категория, способ оплаты, получатель, поездка, комментарий.
- Редактирование расхода: та же форма, заполненная текущими данными.
- Удаление расхода с подтверждением.
- Сохранение расходов на устройстве: данные остаются после перезапуска.
- Восемь стандартных категорий с иконками.
- Свои категории: название, значок и цвет; переименование обновляет расходы, удалить можно только пустую категорию.
- Поездки и командировки: создание с периодом, привязка расходов, итоги за месяц и по категориям, удаление.
- Тёмная тема Red Velvet: фирменный градиент и розовый акцент.
- Нижняя навигация по четырём разделам.
- Русская локализация (даты, календарь, суммы в рублях).

### В планах
- Редактирование поездки.
- Прикрепление чеков (камера и галерея).
- Импорт расходов из CSV с проверкой перед загрузкой.

### Экран обзора
Стартовый экран. Показывает сумму расходов за месяц, кольцевую диаграмму по категориям с легендой (сумма и доля) и столбики расходов за шесть месяцев. Нажатие на столбик выбирает месяц. Переключение между разделами выполняется через нижнюю панель.

<img src="docs/screenshots/overview.png" width="450" />

### Экран расходов
Список всех расходов с поиском по получателю и комментарию. Кнопка внизу экрана открывает форму добавления нового расхода.

<img src="docs/screenshots/expenses.png" width="450" />

### Экран фильтров
Открывается кнопкой «Фильтры» над списком расходов. Показывает, сколько условий активно, и позволяет сбросить их все.

<img src="docs/screenshots/filters.png" width="450" />

### Экран деталей расхода
Открывается по нажатию на расход в списке. Показывает сумму, дату и все данные расхода. Кнопка «Изменить» открывает форму редактирования, красная кнопка удаляет расход после подтверждения.

<img src="docs/screenshots/details.png" width="450" />

### Экран нового расхода
Эта же форма используется для редактирования. Форма с подписями над полями и обязательными пунктами, отмеченными звёздочкой. Категория выбирается из списка, дата - в календаре, способ оплаты - переключателем.

<img src="docs/screenshots/new_expense.png" width="450" />

### Экран поездок
Итог командировок за месяц с долей от всех расходов и карточки поездок с периодом, суммой и количеством расходов. Новая поездка создаётся кнопкой внизу.

<img src="docs/screenshots/trips.png" width="450" />

### Экран поездки
Период и статус (предстоящая, идёт сейчас, завершена), итог за весь период, разбивка по категориям и список привязанных расходов. Расход привязывается к поездке в форме расхода.

<img src="docs/screenshots/trip_details.png" width="450" />

### Экран новой командировки
Название и даты начала и окончания. Внизу показывается длительность и статус поездки.

<img src="docs/screenshots/trip_form.png" width="450" />

### Экран категорий
Стандартные категории (только просмотр) и свои категории с карточкой, значком и цветом. Нажатие на свою категорию открывает её редактирование, кнопка внизу создаёт новую.

<img src="docs/screenshots/categories.png" width="450" />

### Экран своей категории
Название, выбор значка и цвета с предпросмотром. При редактировании внизу есть удаление, доступное, когда в категории нет расходов.

<img src="docs/screenshots/category_form.png" width="450" />


### Запуск проекта
```
flutter pub get
flutter run
```

### Иконка приложения
Исходники лежат в `assets/icon/`. После изменения картинок пересоберите иконки:
```
dart run flutter_launcher_icons
```

### Дизайн
Макеты основаны на Aurora OS UI Kit (тема Red Velvet, Dark). Палитра и компоненты вынесены в папку `lib/theme` и `lib/widgets`.
