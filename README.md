# Трекер

Мобильное приложение для учета доходов и расходов

### Поддерживаемые ОС
- Android (эмулятор, настоящее устройство)
- Aurora OS (эмулятор из sdk 5.1.5)

### Функционал
- Обзор расходов за месяц с разбивкой по категориям.
- Список расходов с поиском и группировкой по датам.
- Добавление расхода: сумма, категория, дата, получатель, комментарий, способ оплаты.
- Восемь стандартных категорий с иконками.
- Раздел поездок и командировок с итогами по каждой.
- Тёмная тема Red Velvet: фирменный градиент и розовый акцент.
- Нижняя навигация по четырём разделам.
- Русская локализация (даты, календарь, суммы в рублях).

### Экран обзора
Стартовый экран. Показывает сумму расходов за месяц и список категорий с итогами по каждой. Переключение между разделами выполняется через нижнюю панель.

<img src="docs/screenshots/overview.png" width="450" />

### Экран расходов
Список всех расходов с поиском по получателю и комментарию. Кнопка внизу экрана открывает форму добавления нового расхода.

<img src="docs/screenshots/expenses.png" width="450" />

### Экран нового расхода
Форма с подписями над полями и обязательными пунктами, отмеченными звёздочкой. Категория выбирается из списка, дата - в календаре, способ оплаты - переключателем.

<img src="docs/screenshots/new_expense.png" width="450" />

### Экран поездок
Карточки командировок за месяц с датами, итоговой суммой и долей в общих расходах.

<img src="docs/screenshots/trips.png" width="450" />

### Экран категорий
Список стандартных категорий приложения с иконками.
